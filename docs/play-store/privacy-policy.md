# 자비스 개인정보처리방침 (초안)

시행일: 2026년 [  ]월 [  ]일

[운영자 이름 또는 상호](이하 "운영자")는 자비스 앱(이하 "앱")을 쓰는 분의 개인정보를 아래와 같이 처리합니다.

## 1. 처리하는 개인정보

| 구분 | 항목 | 언제 수집하나요 |
|---|---|---|
| 계정 | 구글 계정 이름, 이메일 주소, 구글 사용자 식별값 | 구글로 로그인할 때 |
| 음성 | 자비스와 나눈 대화 음성과 그 내용을 글로 옮긴 기록 | "자비스"라고 불러 대화할 때 |
| 사진 | 안경이나 휴대폰으로 찍은 사진(명함, 문서, 미팅 장면) | 사용자가 촬영을 요청할 때 |
| 미팅 기록 | 미팅 요약, 결정 사항, 후속 할 일, 메모 | 미팅을 기록할 때 |
| 인물 정보 | 만난 사람의 이름, 소속, 연락처(명함이나 사용자가 고른 연락처에서 가져옴) | 사용자가 인물을 저장할 때 |
| 얼굴 인식 정보 | 사진 속 얼굴에서 뽑은 특징값(숫자 벡터). 얼굴 사진 자체가 아님 | 얼굴 당사자가 동의하고 사용자가 등록을 요청할 때 |
| 캘린더 | 미팅 브리핑에 필요한 일정 제목, 시간, 참석자 | 브리핑을 받을 때(권한 허용 시) |
| 연동 정보 | 사용자가 연결한 노션, 슬랙, 구글 캘린더의 접근 토큰 | 외부 서비스를 연결할 때 |

연락처와 캘린더는 휴대폰에서 읽어 기능에 필요한 항목만 씁니다. [확인 필요: 이름으로 연락처를 찾을 때 연락처 이름 목록이 AI 처리 업체로 넘어가는지 코드 확인 후 문장 확정]

## 2. 이용 목적
- 계정 확인과 사용자별 데이터 분리
- 음성 대화, 미팅 요약, 후속 할 일 정리, 미팅 전 브리핑
- 명함과 문서 인식, 만난 사람 알아보기
- 문자, 메일 초안 작성과 일정 등록(실제 발송은 사용자가 휴대폰 앱에서 확인한 뒤에 이루어짐)

광고나 마케팅에는 쓰지 않고, 개인정보를 판매하지 않습니다.

## 3. 얼굴 인식 정보(민감정보)
[D37 결정에 따라 정함] 얼굴 인식 정보는 생체인식정보입니다. 얼굴의 주인(만난 상대방)에게서 따로 동의를 받은 경우에만 만들고 저장합니다. 만난 사람을 알아보는 데만 쓰고, 해당 인물을 지우면 함께 지웁니다. 동의 절차를 갖추기 전까지는 이 기능을 쓰지 않습니다.

- 계정을 지우면 서버에 저장된 계정 정보, 미팅 기록, 사진, 음성, 인물과 얼굴 인식 정보, 연동 토큰을 바로 지웁니다. 백업본은 [  ]일 안에 지웁니다.
- 법령에서 보관을 요구하는 정보는 그 기간 동안만 따로 보관합니다.
