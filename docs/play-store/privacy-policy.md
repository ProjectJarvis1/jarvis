| 캘린더 | 미팅 브리핑과 먼저 알려 주기에 필요한 일정 제목, 시간, 참석자 | 권한을 허용하면 앱을 닫아 둔 동안에도 15분마다 휴대폰에서 읽음. 일정 제목과 참석자 이름으로 내 기록을 검색할 때만 서버로 보냄 |

| 연동 정보 | 사용자가 연결한 노션, 슬랙, 구글 캘린더, 지메일의 접근 토큰 | 외부 서비스를 연결할 때 |

| 이용량 | 날짜별 실시간 대화 시간, 회의 정리 횟수, 요청 횟수 | 하루 이용 한도를 지키려고 서비스를 쓸 때마다 셈 |

## 1-1. 지메일 정보
- 지메일은 사용자가 설정에서 직접 연결할 때만 씁니다. 받는 권한은 메일 읽기(gmail.readonly) 하나이고, 메일을 보내거나 지우거나 고치지 않습니다.
- 사용자가 "김 팀장 최근 메일 뭐였지?"처럼 물을 때 그 질문에 맞는 메일만 찾아 읽고, 답을 만들려고 아래 4번의 AI 처리 업체에 보냅니다. 메일 원문은 서버 데이터베이스에 따로 저장하지 않습니다.
- 먼저 알려 주기를 켜 두면 15분마다 새로 온 메일의 보낸 사람, 제목, 미리보기를 확인합니다. 저장된 사람이나 회사와 관련 있거나 협상, 입찰, 견적 같은 업무 메일이면 휴대폰에 알리고, 지난 미팅과 할 일을 함께 모아 보여 줍니다. 미팅 전 브리핑에는 그 상대와 주고받은 최근 메일 몇 통의 제목과 미리보기를 넣습니다. 이 확인에는 AI 처리 업체를 쓰지 않고, 확인한 메일 정보는 서버에 남기지 않고 휴대폰에만 보관합니다.
- 메일 정보는 사용자에게 답하는 데만 쓰고, 광고에 쓰거나 팔거나 사람이 읽게 하지 않습니다. 보안 사고 조사나 법령상 의무, 사용자의 명시적 동의가 있을 때는 예외입니다. AI 모델을 학습시키는 데도 쓰지 않습니다. [확인 필요: Gemini 중계 업체와 Gemini API 이용 조건에서 입력 데이터를 학습에 쓰지 않는지 확정]
- 자비스가 Google API에서 받은 정보를 쓰고 다른 앱으로 보내는 방식은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. (Jarvis's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.)
- 설정에서 지메일 연결을 해제하면 자비스는 메일을 더 읽지 않습니다. 구글 쪽 권한까지 거두려면 구글 계정의 "서드 파티 앱 및 서비스" 화면에서 자비스를 지웁니다.

## 2. 이용 목적
- 계정 확인과 사용자별 데이터 분리
- 음성 대화, 미팅 요약, 후속 할 일 정리, 미팅 전 브리핑
- 명함과 문서 인식, 만난 사람 알아보기
- 문자, 메일 초안 작성과 일정 등록(실제 발송은 사용자가 휴대폰 앱에서 확인한 뒤에 이루어짐)

광고나 마케팅에는 쓰지 않고, 개인정보를 판매하지 않습니다.

## 3. 얼굴 인식 정보(민감정보)
얼굴 인식 정보는 생체인식정보입니다. 얼굴의 주인(만난 상대방)에게서 동의를 받은 경우에만 만들고 저장합니다. 자비스는 얼굴을 저장할 때마다 사용자에게 "상대방이 얼굴 저장에 동의했나요?"라고 확인하고, 사용자가 동의를 받았다고 확인해야만 저장하며 그 시각을 함께 기록합니다. 만난 사람을 알아보는 데만 쓰고, 해당 인물을 지우면 함께 지웁니다.
