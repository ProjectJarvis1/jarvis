# 자비스 계정 삭제 안내 (초안)

자비스 계정과 그 안의 데이터를 지우는 방법입니다.

## 앱에서 지우기
1. 자비스 앱을 엽니다.
2. 설정 > 계정 > 계정 삭제를 누릅니다.
3. 확인 창에서 삭제를 누르면 바로 지워집니다.

## 앱 없이 지우기
앱을 지웠거나 휴대폰을 바꿨다면 admin@projectjarvis.biz 로 메일을 보내 주세요. 제목은 "계정 삭제 요청", 본문에는 자비스에 로그인할 때 쓴 구글 이메일 주소를 적습니다. 그 주소로 본인인지 확인한 뒤 [7]일 안에 지우고 결과를 알려 드립니다.

## 지워지는 데이터
- 계정 정보(이름, 이메일, 구글 사용자 식별값)
- 미팅 기록, 요약, 후속 할 일, 메모
- 사진, 음성 녹음과 대화 기록
- 저장한 인물 정보와 얼굴 인식 정보
- 노션, 슬랙, 구글 캘린더 연동 정보

삭제한 데이터는 되살릴 수 없습니다. 백업본에 남은 데이터는 [  ]일 안에 함께 지워집니다.
